TripPilot AI Prototype

1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. Enter trip details and click “Create My Travel Plan”.

This is a front-end prototype. It intentionally uses illustrative/sample travel data.
For production, connect APIs/services for:
- Visa and immigration information
- Flight search and booking
- Hotel search and booking
- Maps, taxis and transport
- Activities
- Currency exchange
- Travel insurance

The JavaScript is structured so the current sample data can later be replaced by API responses.
